# 🫀 Classificação de Doenças Cardíacas 

Este projeto tem como objetivo aplicar técnicas de **Aprendizado de Máquina** para a **classificação de doenças cardíacas**, utilizando dados clínicos e avaliando o desempenho de **modelos ensemble de classificação**. O foco do trabalho está na **comparação entre diferentes algoritmos baseados em ensembles** e na **interpretação dos resultados**, visando maior transparência e compreensão do processo preditivo.

---

## 🎯 Objetivo

- Aplicar modelos **ensemble** para classificação de doenças cardíacas  
- Comparar o desempenho de diferentes algoritmos ensemble  
- Avaliar os modelos por meio de métricas de desempenho  
- Utilizar técnicas de interpretabilidade para compreender as decisões dos modelos  

---

## 🧠 Metodologia

O projeto contempla as seguintes etapas:

- Análise exploratória dos dados  
- Pré-processamento e preparação do conjunto de dados  
- Treinamento de diferentes **modelos ensemble de classificação**  
- Avaliação comparativa dos modelos utilizando métricas de classificação  
- Interpretação dos resultados com auxílio de gráficos SHAP  

---

## 📊 Resultados

A comparação entre os modelos indicou que **Random Forest** e **Gradient Boosting**, ambos métodos **ensemble**, apresentaram o melhor desempenho entre os classificadores avaliados, alcançando **Accuracy, Precision, Recall e F1-score iguais a 1.0** no conjunto de dados utilizado.

A interpretação dos modelos foi realizada por meio do **SHAP Summary Plot**, que permitiu identificar as variáveis mais relevantes e compreender como seus valores contribuem para aumentar ou reduzir a probabilidade da classe positiva, tornando o modelo mais transparente e interpretável.

Este projeto destaca a aplicação de **modelos ensemble** de Machine Learning na área da saúde, evidenciando a importância da avaliação comparativa e da interpretabilidade para apoiar decisões mais confiáveis e transparentes em problemas de classificação clínica.
